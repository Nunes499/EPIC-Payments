# EPIC Payments

Aplicação interna para gestão de pagamentos, cobranças e comunicação com clientes do Epic Fitness.

## Tecnologias

- Frontend: Next.js
- Backend: FastAPI
- Base de dados: PostgreSQL
- Docker
- TypeScript
- Python
